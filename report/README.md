# Final report (CE893 LaTeX template)

| File | What it is |
|---|---|
| `main.tex` → `main.pdf` | **Full draft** of the report (10 pages, the module limit) |
| `main_outline.tex` → `main_outline.pdf` | **Outline version**: same structure, figures and tables, prose replaced by "Write here" notes |
| `report.tex` | the full text (edit this) |
| `report_outline.tex` | generated by `make_outline.py` from `report.tex`; edit the notes in `make_outline.py` |
| `make_figures.py` | draws every figure in `figures/` from the stored runs in `../results/` |
| `analysis.py` | every number in the report (accuracy, McNemar, breakdowns, error categories, training logs) |
| `preamble.tex`, `ce893.bst`, `essex_logo.png`, `Archivio/` | from the module template (only change: `ce893.bst` prints "et al." with one full stop) |

Build (needs XeLaTeX for the template's Archivo font; pdfLaTeX also works and falls back to Helvetica):

```bash
python report/make_figures.py
python report/make_outline.py
cd report && latexmk -xelatex main.tex && latexmk -xelatex main_outline.tex
```

`main.tex` adds float settings and `needspace` after the template preamble so that figures share
pages with text; the template's look is unchanged. Before submitting: check the PDF is still 10 pages.

The runnable notebook that reproduces all numbers and figures is `../notebook/CE893_evaluation.ipynb`.
