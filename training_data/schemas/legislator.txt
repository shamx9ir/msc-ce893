cube current
  dim  current.row_key (string)
  dim  current.ballotpedia_id (string) -- The ballotpedia.org page name for the person (spaces are given as spaces, not underscores). if this value is null or empty, it means this legislator doesn't have account on ballotpedia.org
  dim  current.bioguide_id (string) -- The alphanumeric ID for this legislator
  dim  current.birthday_bio (time) -- The legislator's birthday, in YYYY-MM-DD format.
  dim  current.cspan_id (number) -- The numeric ID for this legislator on C-SPAN's video website, if this value is null or empty, it means this legislator doesn't have account on C-SPAN's video website
  dim  current.fec_id (string) -- A list of IDs for this legislator in Federal Election Commission data. if this value is null or empty, it means this legislator hasn't not been registered in Federal Election Commission data.
  dim  current.first_name (string) -- first name of the legislator
  dim  current.gender_bio (string) -- gender of the legislator
  dim  current.google_entity_id_id (string) -- google entity id if this value is null or empty, it means this legislator are not google entities
  dim  current.govtrack_id (number) -- The numeric ID for this legislator on GovTrack.us if this value is null or empty, it means this legislator doesn't have account on GovTrack.us
  dim  current.house_history_id (number) -- The numeric ID for this legislator on http://history.house.gov/People/Search/ The ID is present only for members who have served in the U.S. House.
  dim  current.icpsr_id (number) -- The numeric ID for this legislator in Keith Poole's VoteView.com website, originally based on an ID system by the Interuniversity Consortium for Political and Social Research (stored as an integer). if this value is null or empty, it means this legislator doesn't have account on VoteView.com
  dim  current.last_name (string) -- last name of the legislator
  dim  current.lis_id (string) -- The alphanumeric ID for this legislator found in Senate roll call votes The ID is present only for members who attended in Senate roll call votes
  dim  current.maplight_id (number) -- The numeric ID for this legislator on maplight.org if this value is null or empty, it means this legislator doesn't have account on maplight.org
  dim  current.middle_name (string) -- the middle name of the legislator
  dim  current.nickname_name (string) -- nickname of the legislator
  dim  current.official_full_name (string) -- official full name
  dim  current.opensecrets_id (string) -- The alphanumeric ID for this legislator on OpenSecrets.org. if this value is null or empty, it means this legislator doesn't have account on OpenSecrets.org.
  dim  current.religion_bio (string) -- The legislator's religion.
  dim  current.suffix_name (string) -- suffix name
  dim  current.thomas_id (number) -- The numeric ID for this legislator on http://thomas.gov and http://beta.congress.gov. if this value is null or empty, it means this legislator doesn't have account on both http://thomas.gov and http://beta.congress.gov.
  dim  current.votesmart_id (number) -- The numeric ID for this legislator on VoteSmart.org if this value is null or empty, it means this legislator doesn't have account on VoteSmart.org
  dim  current.wikidata_id (string) -- the id for wikidata
  dim  current.wikipedia_id (string) -- The Wikipedia page name for the person if a legislator has wikipedia id, it means he or she is famous or impact
  meas current.count (count)
